## Design decisions (orchestrator defaults; revisit if the owner disagrees)

- Unlocks: everything that exists in the player's install is unlocked
  (towers, archers, variants); optional import of `tf_savedata` stats later.
- 9–12 players: extrapolate the 8-player build's rules (chest-count chances,
  spawns, HUD). The 12-arrows-in-level cap scales with player count
  (12 for ≤ 4, ×1.5 for 5–8, ×2 for 9–12) — tune by playtest.
- Treasure draft quirk with even teams (Red treated as leader) is kept for
  fidelity in ≤ 4 player matches.
- Duplicate archers for 10–12 players: alt skins first, then the same archer
  with a team/player colour tint (needs a look by eye).

- Randomness: gameplay and cosmetic draws use separate seeded streams
  (the original shares one global generator and uses unseeded ones in a few
  places: level order, procedural seed, spikeball spin). All derived from the
  match seed so peers agree.
- Quirks: keep the original's behavioural quirks that affect feel or layout
  (e.g. CrumbleBlock's 2 px wider collider, platform timers running from level
  load); fix only crashes and slot-count limits (arrays sized 4 or 8,
  `x != 160` mirror-spawn test in 8p).
- Width-dependent constants (side-lava reach 30 px @320 / 50 px @420, Miasma
  width …) are taken per width from the two builds; other widths interpolate.
